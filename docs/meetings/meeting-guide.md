# Meeting guide

Create one `YYYY-MM-DD-topic.md` file per meeting using the template below. Use the meeting date in KST when known. List the record under its iteration in [README.md](README.md).

Work from the supplied notes. Record participants, decisions, and owners as stated. Use “Not recorded” for missing information and keep proposals distinct from decisions. Retain the original notes link when available. Review the record against the notes before publishing an entry to the [Daily Standup Meeting Log](https://github.com/snuhcs-course/swpp-2026-project-team-07/wiki/Daily-Standup-Meeting-Log). Append the approved entry under the correct iteration and verify it appeared in the Wiki. The Wiki retains full entries for course access.
