#### Notes

- The user-story exercise due September 23 is marked “check” in the original to-do list.
- **Differentiation:** Compare Microsoft Speaker Coach and Yoodli with the proposed slide-and-speech feedback workflow. Clarify what the app adds beyond speaking speed or delivery feedback.
- **Evidence and scope:** Explain how insufficiently supported claims will be identified, and whether evidence comes from presentation materials or external sources. Describe how feedback connects a speech passage with a slide and explains the issue.
- **Technical approach:** Specify whether and how an LLM is used. Consider slide visuals and charts, and define how audio information would support any pace or intonation analysis.
- **Feasibility:** Test the full flow early with a short presentation. Check recognition quality, processing time and API cost; collect real presentation materials and human feedback early.
- **Reliability and priorities:** Stabilize saving, feedback review and repeated practice for user testing. Plan for API errors. TA feedback suggested placing Q&A and support for multiple devices after core presentation feedback.
