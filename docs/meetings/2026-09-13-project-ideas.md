#### Participants and objective

- **Time / location / participants:** Zoom/ All participated
- **Objective:** Explore project ideas, their intended users, strengths and implementation concerns.

#### Agenda

- Compare five possible project ideas.

#### Notes

1. **Intrapersonal diary with friends and partners:** Share personal perspectives after spending time together. Potential users include couples, families and friends. Strengths discussed were social connection, a relatively simple concept and a potentially large user base. Concerns included the personal nature of a diary, the burden of daily writing, AI integration and database/server needs.
2. **Presentation feedback app:** Provide slides and a time limit, rehearse through a microphone, and receive feedback on the presentation, tone, diction and speed. Intended users include students and workers. Concerns included long presentation inputs, processing delay, feedback accuracy, security and storage.
3. **Location-based language learning:** Use places where the user spends time to generate relevant language exercises. Strengths included personalization and immersive learning. Concerns included adapting exercises to proficiency and inaccurate GPS tracking.
4. **Museum/exhibition AI tour guide:** Generate an interactive guide for a visit. The discussion raised usefulness compared with existing search tools, possible hallucinations and a small user base.
5. **Podcast highlighter:** Save quotes and find them through text rather than timestamps. Possible users include writers and journalists. Concerns included a similar existing feature, limited AI use and access/privacy issues around podcast audio.

#### Decisions

Decided on Presentation feedback app
